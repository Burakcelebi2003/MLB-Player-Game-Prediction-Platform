# MLB-Player-Game-Prediction-Platform
MLB game and player performance prediction using statistical modeling, time series methods, ensemble forecasting and machine learning.

This project develops a data-driven MLB match projection system designed to estimate team scoring performance and evaluate potential game outcomes.

The framework analyzes both teams independently by combining historical run production, offensive sabermetrics, starting pitcher performance, and bullpen efficiency.

The main objective is to generate expected runs for the Away and Home teams, estimate winning probabilities, and evaluate possible score distributions through an ensemble forecasting architecture.

Unlike a conventional prediction model based solely on team averages, this project integrates classical time-series forecasting methods with machine learning algorithms.


This project focuses on predicting individual MLB player performance by combining historical game-log data, sabermetric indicators, recent performance trends, and machine learning algorithms.

The primary objective is to estimate a player's expected Hits and Runs Batted In (RBI) by evaluating both long-term performance and short-term offensive form.

Rather than relying on static season averages or manually assigned weights, the system transforms historical game logs into supervised learning observations and compares multiple machine learning models to identify the most suitable prediction algorithm.
